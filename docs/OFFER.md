## 交付验收清单

**落地 / 诊断**，每一条都当着你的面跑一遍，跑不过不算交付：

- [ ] `dsh web` 能启动，浏览器打开无报错
- [ ] 模型可用：发一句话能正常回复
- [ ] 权限模式为 `workspace-write`，授权弹窗正常
- [ ] 所装插件逐个列出：来源仓库、读取了哪些权限

- [ ] 交接文档交付，你能照文档自己重启 / 升级 / 卸载

**插件定制**，开工前先签一页[需求单](REQUIREMENT-TEMPLATE.md)，交付按需求单逐条对：

- [ ] 需求单写清：插件做什么、什么时候触发、输出什么、明确不做什么
- [ ] 只读：不注册工具、不注入提示词、不调用模型（除非需求单写明并单独定价）
- [ ] 单元测试覆盖：事件解析白名单、异常降级、卸载清理
- [ ] `npm run build` 零错误，`dsh plugin --profile web add` 安装成功

- [ ] 演示一次真实场景，你确认符合需求单
