## 7. 验收方式

- [ ] `npm run build` 零错误
- [ ] `dsh plugin --profile web add <插件>` 安装成功，重启后生效
- [ ] 单元测试覆盖：事件解析白名单、异常降级、卸载清理
- [ ] 现场演示一次真实场景，客户确认符合第 3、4 节
- [ ] 交接：源码 + 测试 + 文档，全部归客户

## 8. 变更规则

- 验收前提出的小调整（同一功能内）：免费，1 轮。
- 新增功能、改触发条件、改输出形态：视为新需求，重新报价。
- 因客户环境问题（Node 版本、权限、网络）导致的失败，不计入返工。

## 9. 中止

- 客户要求改为"自动养号 / 刷评论 / 账号代运营 / 冒充真人"：立即中止，全额退。
- 需求单确认后客户连续 7 天不回复：按已完成进度结算，剩余退回。
