## V2EX 版（最推荐先在这发）

**标题：[开源] 等 agent 跑代码的那 20 分钟，我在对话框旁边养了只鲸鱼**

---

说个有点社死的事。

前阵子每天晚上派给 agent 一个任务，改 bug 也好写脚本也好，动不动就十几二十分钟。我这个人吧，又忍不住切回去看——生怕它卡死了、跑飞了、把我文件删了。

于是就陷入了一个循环：切回来看一眼 → 还在跑 → 切出去刷五分钟手机 → 又切回来看一眼 → 还在跑……

有天晚上我盯着那个转圈的 loading 发呆，突然想：**这段等待时间，难道就不配被设计一下吗？**

旅行青蛙你们玩过吧？青蛙出门旅行你啥也干不了，就等着它寄明信片回来。那个等待其实一点都不无聊，反而有点期待。

那我为什么不能给我的 agent 也养一只这样的青蛙？

---

于是就做了这个东西：**Whale Voyage**，一个 dsh 插件。

它干的事特别简单：在你对话框右下角养一只小鲸鱼。
- agent 在干活的时候，它就潜下去，水色变深，冒泡泡
- agent 跑完了，它"哗"地浮上来喷个水，庆祝
- 要是任务特别长（超过你自己平时任务时长的 70%），它就寄回一张明信片回来

明信片不是随便画的——上面盖着"邮戳"：这次跑了多久、改了几个文件、测试过没过。

**最关键的是：它完全是个旁观者。** 不注册工具、不注入提示词、不调模型、不花一个 token。agent 根本不知道它存在。我做这个东西的时候给自己定了条死规矩：只要它对 agent 的行为有哪怕一点点影响，我就删了重写。

现在用了两周，最大的变化是：**我居然不焦虑了。** 看到鲸鱼在那里游着，就知道"哦它还在干活"，不用反复切回去确认了。它寄回来的那张珊瑚苗圃明信片，我真的存下来了——上面写着"航次 #7，耗时 14 分钟，修改 3 个文件，测试通过"。

像养了个电子宠物，又像有个同事在旁边陪你加班。

---

开源了，MIT，63 个测试全绿。

GitHub：https://github.com/wzysbkzsd/dsh-whale-voyage

有 dsh 的朋友欢迎试试，没 dsh 的……也可以先 star 一个，万一以后用上了呢（狗头）。

## 即刻版（更短、更碎碎念）

等 agent 跑代码等到焦虑，于是我在对话框旁边养了只鲸鱼 🐋

它现在是我的值班监控：
· 它潜下去 = agent 还在干活
· 它浮上来喷水 = 任务做完了
· 长任务它会寄明信片回来，上面印着改了几个文件

最爽的是它完全不干扰 agent，纯旁观，零 token。我摸它头还能涨亲密度，现在已经从"初识"变"相熟"了。

谁懂啊，加班的时候旁边有个小东西陪着，居然没那么煎熬了。

## 小红书版

**标题：等 AI 跑代码的那 20 分钟，我养了只鲸鱼🐋**

谁懂啊！！每次派任务给 AI，少则 10 分钟多则半小时，那段时间我根本没法专心干别的——总忍不住切回去看它跑完没有😭

然后我自己写了个小插件，在对话框旁边养了只小鲸鱼：

🌊 它潜到水下 = AI 在干活
🐳 它浮上来喷水 = 跑完了！
📮 长任务它会寄明信片回来！珊瑚苗圃、磷虾集市、海沟边缘……

每张明信片上还盖着"邮戳"：跑了多久、改了几个文件、测试过没过。像翻一本自己的航海日志。

最绝的是它完全不干扰 AI，纯旁观，不花一个 token。摸它头还能涨亲密度，摸多了会戴围巾提灯笼（旅行青蛙那味儿了）。

开源了！有同样等 AI 等到焦虑的姐妹一定要试试👇

## 发帖节奏建议

1. **先发 V2EX**，标题用那个"等 agent 跑代码的那 20 分钟"，这是核心故事
2. **过 1-2 小时发到即刻**，用碎碎念版，加 hashtag #独立开发者 #AI工具 #开源
3. **小红书可以晚一点发**，配 hero 图 + GIF 截图，视觉为主
4. **Reddit 英文版**可以后面再补，先把中文社区跑通

**不要做的事：**
- 不要一开始就列功能清单，没人看
- 不要说"我做了一个 XX 插件"，要说"我为什么要做这个"
- 不要过度谦虚也不要吹牛逼，就讲真实的等待焦虑
- GIF 一定要放，动图比文字有说服力 10 倍
